# Legacy Prototype (기존 정적 프로토타입)

이 폴더는 Stitch 기반의 기존 정적 프로토타입 파일들을 안전하게 보존하기 위한 공간입니다.

## 주의 사항
- 이 폴더 내의 파일들은 실제 Next.js 서비스 코드의 **Source of Truth가 아닙니다.**
- 과거 화면 디자인, 레이아웃 및 비즈니스 로직 참고용으로만 사용합니다.
- Production 환경에서 직접 사용하거나 배포하지 않습니다.
